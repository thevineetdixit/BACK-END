why do we switch from SQL to NOSQL? 
The primary reason to switch from SQL to NoSQL is to achieve horizontal scalability, high write/read speeds, and schema flexibility when handling massive amounts of unstructured or semi-structured data. While relational SQL databases excel at maintaining strict consistency and complex relationships, they face structural limitations when scaled across multiple distributed servers. [1, 2, 3, 4]
